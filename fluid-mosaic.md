# Fluid Mosaic

**Source:** https://www.framer.com/marketplace/components/fluid-mosaic/
**Author:** DariStudio
**Price:** $7
**Category:** Premium Carousel / Photo Grid Component

## Description
An interactive photo grid that reshapes based on cursor movement — "Photos that flow with your cursor." Nearby images expand while surrounding cells compress smoothly, maintaining visual continuity throughout the interaction.

## Key Features
- Cursor-responsive grid deformation with smooth motion
- Adjustable response and effect strength settings
- Subtle image parallax effect for depth perception
- Supports up to 12 photos with individual titles, captions, and links
- Configurable lens radius, gaps, corners, overlays, and colors
- Full typography customization controls
- Responsive mobile layout included
- Static Canvas preview for editing convenience
- No external dependencies required
- Native Framer customization

## How It Works
The component creates a fluid, tactile gallery experience where pointer position triggers real-time grid deformation. Images near the cursor expand while distant cells compress, with parallax layering adding dimensional depth.
